# AI Language Translation Tool

## Project Description

The AI Language Translation Tool is a Python-based application developed as part of my Artificial Intelligence Internship at CodeAlpha.

The tool allows users to enter text, select a source language and target language, and translate the text using a translation API. The translated result is displayed directly in the application.

## Features

- Translate text between multiple languages
- Source and target language selection
- Simple and user-friendly GUI
- Translation API integration
- Copy translated text
- Clear input and output
- Error handling for connection issues

## Technologies Used

- Python
- Tkinter
- Requests
- Translation API

## How It Works

1. Enter the text you want to translate.
2. Select the source language.
3. Select the target language.
4. Click the **Translate** button.
5. The translated text will appear in the output section.
6. Use **Copy Translation** to copy the result.
